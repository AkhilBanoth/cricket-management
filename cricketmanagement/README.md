Cricket Management System

A simple Python-based Cricket Management System created using OOPs concepts.

 Features

* Add player
* View players
* Search player
* Remove player
* Update wickets
* Update matches
* Update team
* Update role
* Calculate player performance
* View player summary

 🛠️ Technologies Used
* Python
* OOP (Classes & Objects)
* Lists
* Functions
* Conditional Statements
* Loops

 ▶️ How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in the terminal.
4. Run:

```bash
python cricket_management.py
```
